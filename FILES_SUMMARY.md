## How to Access Patterns in WordPress

1. Go to WordPress admin: `http://localhost:8888/wp-admin`
2. Edit any page
3. Check "Use Gutenberg Block Editor" checkbox
4. Click "+" to add a block
5. Navigate to "Patterns"
6. Select "One More Tree Patterns" category
7. Choose any pattern and click to insert
