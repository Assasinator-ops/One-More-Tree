## How to Use

### Enable Gutenberg for a Page
1. Go to any page in WordPress admin
2. Edit the page
3. Check "Use Gutenberg Block Editor" checkbox
4. Update the page

### Insert a Pattern
1. Click "+" to add a block
2. Navigate to "Patterns"
3. Select "One More Tree Patterns"
4. Choose a pattern variant
5. Click to insert

### Switch Between Designs
1. Delete existing pattern
2. Insert new pattern variant
3. Content remains editable
4. Design updates instantly
